# Features

> 功能需求清单（人工维护）。每条需求一个 `## ` 小节，编号 `F001`、`F002` … 顺序递增、不复用；linked worktree 中自动编号会追加分支限定，如 `F001@branch-slug`。
>
> 录入方式：对 AI 说“新建 feature: <标题>”，或手动复制下方模板。
>
> `status`：`proposed`（默认，待人工复核）→ `accepted`（已确认、可规划）→ `done`（已交付）。仅当用户明确授权录入并继续规划、内容忠实且不存在实质歧义时，AI 才可直接记录为 `accepted`；否则保持 `proposed` 并等待复核。`accepted` 只批准规划，不批准实施。
>
> 正文只记录需求意图。能说清时用一段话概括要做什么、主要范围、验收结果和关键限制；设计决策、替代方案与风险论证留给 RFC，执行任务留给 plan。
>
> `requires_rfc: true` 为可选字段，缺失时按 `false`。人类明确要求或 AI 说明实质设计风险后可启用；需要 RFC 的 feature 必须先完成独立设计审批，再进入计划审批，具体格式由 Superplan RFC 流程管理。

## F001: 错字 Boss 打败后第 7 天、第 15 天复查

- status: done
- created: 2026-10-19

连续答对 3 次打败的字，在第 7 天和第 15 天各回来复查一次；复查答错就重新回到错字 Boss，两次复查都答对才算彻底记住。用户 2026-10-19 确认需要，并已在平板上试用写字功能（感觉还行）。

## F002: 闯关防乱点：孩子注意力分散时提醒并保护成绩

- status: done
- created: 2026-10-19

用户反馈：孩子玩一会后会瞎点，注意力不在题目上。期望：闯关中出现连续乱点、答得过快时，提醒孩子慢下来或休息，乱点的作答不应让游戏变成随便点。

## F003: 孩子界面的题目和说明加注拼音

- status: done
- created: 2026-10-19

用户反馈：游戏内的题目或说明最好加上拼音。期望：闯关、错字 Boss、写字练习等孩子界面中的说明、题目、选项和按钮文字带拼音。

## F004: 闯关界面调整：部首侦探题目与选项间距，去掉字族收藏

- status: done
- created: 2026-10-19

用户反馈：部首侦探能看懂，但问题和选项距离有点近；字族网络的“我的收藏”感觉用不上，可以去掉。

## F005: 生字闪认录音纠错：读出来自动判断，不用自己点

- status: done
- created: 2026-10-19

用户希望生字闪认增加录音纠错功能，孩子读出来后自动判断对错，不用自己去点。方案（在线识别 / 离线识别 / 录音回放）待在用户平板上实测在线语音识别后决定（2026-10-19）。实测结果：浏览器支持语音识别接口，但点击后一直“正在听”、说话无任何反应（连不上在线识别服务）。用户选定方案：读出声自动翻页 + 录音回听（离线、不上传），限时过程中不用点“认识”。

## F006: 生字闪认读错当场纠正：读完听标准音自己对，错了重读

- status: done
- created: 2026-10-19

用户反馈：声音模式下读错了不应该继续，应给出反馈再重新读。用户选定做法：孩子读完后立即播放“你读的”和标准读音（显示拼音），孩子点“一样 / 不一样”；不一样就提示再读一遍并重新录音，直到读对再进入下一个字；纠错时倒计时暂停。
