# PRD：汉字闯关 —— 科学、有趣的小学低年级语文学习系统

> 项目需求来源。描述目标、范围、约束、验收标准与非目标。
> 由 `$project-bootstrap-from-prd` 读取并拆分为 `docs/superplan/plans` 下的执行计划。

- 版本：v0.4
- 日期：2026-10-19
- 状态：需求已确认（见第 10 节“已确认决策”）

## 1. 背景与定位

很多孩子觉得语文就是“重复的读、写、背”，在家练习容易失去耐心；而孩子天生对有逻辑、有挑战、生动的事物感兴趣。

本系统的目的，是给小学低年级（一、二年级）学生提供一套**科学、有趣的语文学习方法**：

- **科学**：依据学习科学的成熟结论（间隔复习、主动回忆、汉字构字规律、适度挑战等）安排学什么、什么时候复习、练多少。
- **有趣**：把语文学习从“机械重复”变成“破解规律 + 闯关”：部首推理、字族网络、错字 Boss、侦探式看图写作，以及经验值和等级激励。

系统面向**不同基础的孩子**，自动走不同的路线：

| 孩子的情况 | 学习路线 | 目标 |
|---|---|---|
| 基础薄弱，落后于课本进度 | **补漏路线**：优先补上以前没掌握的字 | 追上学校进度 |
| 基本跟上 | **同步路线**：预习、复习当前课本内容 | 稳固课内、少量提升 |
| 基础好，课内已掌握 | **拓展路线**：超前学习、课外常用字、更高的写作挑战 | 在兴趣中继续提高 |

## 2. 目标

| 编号 | 目标 | 衡量方式 |
|---|---|---|
| G1 | 课内识字稳固：跟上或超过学校进度 | 本学期生字认读正确率 ≥ 90%，书写正确率 ≥ 85% |
| G2 | 识字量持续增长 | 基础好的孩子：课外常用字认读量按月增长；识字量曲线持续上升 |
| G3 | 写作能力逐级提升 | 写作等级按阶梯提升；二年级末至少能写一段有起因、经过、结果的短文 |
| G4 | 兴趣与习惯 | 每周主动使用 ≥ 5 天；每段使用不超过 15～20 分钟 |
| G5 | 家长掌握现状 | 家长能看到识字量曲线、学习路线进度、错字清单和每 4 周的复评对比 |

## 3. 用户与角色

| 角色 | 说明 | 主要诉求 |
|---|---|---|
| 孩子（主用户） | 小学一、二年级，基础可强可弱 | 好玩、有挑战、能看到自己变强；文字少、有语音、操作简单 |
| 家长（管理者） | 陪伴学习、判分、看进度 | 快速了解孩子的强项和薄弱点；设置学习内容和强度；低成本陪伴 |

- 孩子模式与家长模式分开，家长模式用 PIN 进入。
- 只支持一个家庭、一个孩子、一台设备；不做多孩子、多设备同步。

## 3A. 学习科学原则

每个功能都对应一条学习原则，避免“看起来热闹、实际没效果”。

| 原则 | 含义 | 对应功能 |
|---|---|---|
| 间隔复习 | 在快要遗忘时复习，比集中重复记得更牢 | 错字 Boss 按第 1、2、4、7、15 天复习（4.4） |
| 主动回忆 | 自己想出答案，比反复看、反复抄更有效 | 闪认、默写、部首推理都是“先想再看答案” |
| 构字规律 | 大部分常用汉字是形声字，形旁表义、声旁表音 | 部首侦探、字族网络（4.3） |
| 适度挑战 | 难度略高于当前水平时学得最好、最投入 | 闯关难度随正确率自动升降；拓展路线（4.5） |
| 短时分段 | 低年级孩子专注时长有限 | 每关 3～5 分钟，每段不超过 15～20 分钟 |
| 先说后写 | 先把想法说清楚，再落到纸上，降低写作难度 | 侦探看图写作（4.6） |
| 即时反馈 | 当场知道对错和原因 | 部首推理揭晓依据；书写逐笔判断 |
| 内在动机 | 看见自己的进步，比外部奖惩更持久 | 只加不扣的经验值、识字量曲线、个人纪录 |

## 4. 范围与功能需求

优先级：P0 = MVP 必须，P1 = 第二阶段，P2 = 以后再说。

### 4.1 字库与课本进度（P0）

- **课本字库**：内置部编版（统编版）一年级上册、一年级下册、二年级上册、二年级下册共 4 册的“识字表”和“写字表”，按“册 → 单元 → 课”组织。
- **拓展字库**：内置《通用规范汉字表》一级字表（3500 个常用字）中课本之外的字，按常用程度排序，供拓展路线使用。
- 初始数据由开发方根据公开资料整理；家长之后可以在家长模式中自行核对和修改。
- 每个字的数据包括：拼音、部首、结构、笔画数、常用组词、构字信息（形旁、声旁）、所属字族，以及可选的字理说明。
- 家长可以设置“当前学到第几课”。课内出题来自已学和当前课；预习取下一课；是否允许“超前学习”后续课程由家长开关控制。
- 家长可以手动添加或修改字词，用于补充老师额外布置的内容。

### 4.2 现状评估中心（P0）

用于首次摸底，并支持每 4 周复评。

1. **课内认读抽测**：从已学识字表中按册随机抽字，一屏一个大字。孩子读出来，家长点“对”或“错”。按正确率估算课内识字量（正确率 × 已学总字数），并生成“待攻克清单”。
2. **拓展认读抽测**：课内认读正确率 ≥ 90% 时自动加测，从未学的后续课本字和拓展字库中分层抽字，估算课外识字量。
3. **听写**：系统用语音朗读字词，孩子在纸上写。家长逐个标记“写不出 / 写错 / 正确”。
4. **组词与词语理解**：屏幕出字或词，孩子口头回答，家长判定对错。
5. **朗读计时**：家长选一篇文本（可粘贴），计时并记录卡顿次数，最后算出每分钟读多少字。
6. **看图写作评分**：家长上传图片或照片，按评分表打分（要素、顺序、句子、细节、书写，每项 1～3 分），可附孩子作文的照片；家长再对照写作等级阶梯（见 4.6）选出孩子当前达到的等级。
7. **评估报告**：汇总课内识字量、课外识字量、书写正确率、写作等级；给出建议学习路线（补漏 / 同步 / 拓展）、建议练习级别和优先补强方向；保存为历史，供复评对比。

### 4.3 汉字闯关（P0：前 3 个玩法；P1：其余）

每关 3～5 分钟，难度随正确率自动升降。最高难度会出现拓展字，基础好的孩子也有挑战空间。

| 玩法 | 优先级 | 说明 |
|---|---|---|
| 部首侦探 | P0 | 给一个形声字，孩子推理它的读音（选项）和意思类别（选项），再揭晓答案和推理依据 |
| 字族网络 | P0 | 以声旁为中心（如“青”），把偏旁拖进去组成新字，组成后显示读音、组词，最后生成导图；拓展路线可以组出课外字 |
| 生字闪认 | P0 | 限时快速认读生字，挑战自己的最好成绩 |
| 字理故事 | P1 | 象形字、会意字的演变卡片（图示 + 简短说明），看图猜字 |
| 汉字积木 | P1 | 给出一组部件，限时尽量多地拼出字 |
| 找不同 | P1 | 易混字对比（己/已/巳、买/卖），选出正确的字填进句子 |
| 字谜 | P1 | 猜字谜；孩子也可以自己编字谜存进“我的字谜库”，去考家长 |

### 4.4 错字 Boss（P0）

- 来源：评估、闯关、默写中出错的字，以及补漏和拓展中新学的字，自动加入；家长也可以手动加入。
- 按第 1、2、4、7、15 天的间隔安排复习。连续 3 次正确视为“击败”，移进“战利品”。复习时出错，间隔重新开始。
- 每日复习以“Boss 战”的形式呈现，显示 Boss 血条，即剩余待复习数量。

### 4.5 每日任务、学习路线与练习级别（P0）

#### 4.5.1 每日任务类型

- 预习“侦察任务”：下一课生字，先推理读音和意思。
- 当天复习：本课生字闪认。
- **新字任务**：每天按配额学一批新字，内容由学习路线决定（见 4.5.2）。先用部首侦探或字族学一遍，需要会写的字再描红，然后放进错字 Boss 按间隔复习。
- 错字 Boss 战。
- 阅读打卡。
- 每周末生成“周 Boss 战”：从本周学过的字中抽 20 个，认读 + 默写，记录正确率并与上周对比。
- 单元结束时，生成单元挑战。

#### 4.5.2 三条学习路线（系统自动切换）

| 路线 | 进入条件 | 新字任务取什么字 |
|---|---|---|
| 补漏 | 待攻克清单不为空，或存在以前学过但从未答对的字 | 待攻克清单和以前没掌握的字，按课本顺序先早后晚 |
| 同步 | 补漏清单已清空，但还不满足拓展条件 | 本课和下一课中尚未掌握的字 |
| 拓展 | 补漏清单已清空，且周 Boss 正确率连续 2 周 ≥ 90%；或首次评估课内认读 ≥ 90% 且书写 ≥ 85% | ① 超前学习后续课程的字（家长开启时）；② 已学字所在字族中的课外常用字；③ 拓展字库中按常用程度排序的字 |

- 路线切换时提示家长，家长可以手动锁定某条路线。
- 拓展路线的写作任务同时升级：写作等级目标提高一级（见 4.6）。

#### 4.5.3 三个练习级别（控制每天练多少）

| 级别（孩子看到的名称） | 适用情况 | 每日时长 | 新字/天 | 错字 Boss 上限 |
|---|---|---|---|---|
| 轻松（日常巡逻） | 维持状态；或当天学校作业多、状态不好 | 约 15 分钟，1 段 | 0 | 10 张 |
| 标准（侦探训练） | 日常学习 | 约 20 分钟，1 段 | 3 | 15 张 |
| 加强（特训营） | 基础薄弱需要追赶，或基础好想多学一些 | 约 30 分钟，分两段，每段 ≤ 15 分钟，中间休息 5 分钟 | 8 | 25 张；周末加一次 15 分钟“特训闯关” |

- 级别和路线是两个维度：级别决定**练多少**，路线决定**练什么**。例如“加强 + 补漏”用于追赶进度，“加强 + 拓展”用于基础好的孩子继续提高。
- 新字数量、Boss 上限、时长都有默认值，家长可以在级别内微调。
- **防过载**：错字 Boss 待复习数已超过当日上限时，当天自动减少新字数量，先消化已有的；超出上限的卡顺延到第二天，不惩罚。
- **级别由家长决定，系统只提建议**：
  - 评估后：课内认读正确率 < 75% 建议“加强”（补漏路线）；其他情况建议“标准”。基础好的孩子如果想多学，家长可以选“加强”（拓展路线）。
  - 连续 3 天没完成必做任务：提示家长考虑降一级，先保护积极性。
  - 周 Boss 正确率连续 2 周 < 70%：提示可以升一级，或者检查新字是否太多。
- 当天可以临时切换为“轻松”（比如学校作业多），不影响第二天的级别。
- 家长看板显示当前路线的进度：补漏路线显示“已攻克 / 剩余”和“预计还需几周补完”；拓展路线显示课外新学字数和增长趋势。

### 4.6 侦探看图写作与写作等级（P0：引导流程与等级；P1：漫画分镜）

**引导流程：**

1. **找线索**：显示图片，依次问“时间、地点、人物、事件”，孩子可以语音或文字回答，家长也可以代为记录。
2. **推理**：用“因为……所以……结果……”的模板把线索串成故事线；多幅图时每图一句。
3. **写报告**：孩子在纸上写，或在屏幕上输入。
4. **句子升级**：给出 1～4 级示例，孩子自评“这句是几级”，并挑战升一级。
5. 结果由家长按评分表打分，记入历史。
6. P1：漫画分镜。孩子画 4 格（画布或拍照上传），再写成文字。

**写作等级阶梯：**

| 等级 | 目标 |
|---|---|
| 1 | 写出 3 句完整的话 |
| 2 | 5 句以上，时间、地点、人物、事件齐全 |
| 3 | 一段话（8～10 句），有起因、经过、结果 |
| 4 | 有开头和结尾的短文，加入动作、语言、心情等细节 |
| 5 | 恰当使用比喻、拟人等修辞和积累的好词 |

- 家长评分达到当前等级目标 2 次后，提示升到下一级；每次写作任务按当前等级给出提示和示例。
- 基础薄弱的孩子从 1 级开始；基础好的孩子按评估结果直接从较高等级开始。

### 4.7 阅读打卡与词库（P0：打卡；P1：词库）

- 阅读打卡：记录书名和时长，一键完成，读完一本书获得奖励。
- 我的词库：按动作、心情、颜色、声音分类收集好词。写作时可以在侧边栏查看。
- 内置推荐书单（按难度分为入门、进阶），仅含书名和简介，不包含正文。

### 4.7A 描红与屏幕书写（P0）

- **描红**：显示田字格和浅色字形，先播放笔顺动画，孩子用手指逐笔描写；笔画错了即时提示，可以重写。
- **默写**：不显示字形，只播放读音、显示拼音和组词，孩子在田字格里按笔顺写出来。系统逐笔判断，连续写错 3 笔后给出提示。
- 判断依据是“该字的标准笔顺”（使用开源笔顺数据逐笔比对），不做任意手写识别。
- 书写结果计入正确率；默写出错的字自动进入错字 Boss。
- 描红和默写可以用在生字复习、错字 Boss 战和周 Boss 战的书写部分。
- 课本字和拓展字都支持描红和默写。

### 4.8 激励系统（P0）

- 获取经验值：攻克 1 个字 +1，写作升一级 +5，读完 1 本书 +20，完成每日任务 +10（加强级别完成两段 +20）。
- 等级称号从低到高：汉字学徒 → 部首侦探 → 字族猎人 → 文字大师（具体阈值待设计）。
- 只加分不扣分；不做排行榜，只和自己的历史比。
- 家长可以设置“经验值兑换体验奖励”的清单，例如选周末去处。兑换由家长确认。

### 4.9 家长看板（P0）

- 识字量曲线：课内认读、书写、课外识字三条线，按评估和周测数据更新。
- 当前学习路线、练习级别、系统的建议，以及路线进度（见 4.5.3）。
- 写作等级和历次写作评分。
- 当前错字清单、Boss 击败率、连续打卡天数、每日用时。
- 评估历史对比，每 4 周一次。
- 课本进度设置、超前学习开关、字词管理、奖励清单设置、使用时长上限设置。
- 数据导出和导入（JSON），用于备份或换设备。

## 5. 非功能需求

| 类别 | 要求 |
|---|---|
| 平台 | 主要设备为安卓平板（Chrome 浏览器）横屏，同时兼容电脑浏览器；手机可用但不重点优化 |
| 儿童可用性 | 按钮大（≥ 48px）；文字少、字号大；关键提示有语音朗读；所有汉字可点击发音和显示拼音 |
| 时长控制 | 每段使用时长随练习级别而定（轻松 15 分钟、标准 20 分钟、加强每段 15 分钟），达到后提示休息；家长可以调整 |
| 离线与隐私 | 数据默认保存在本机，不需要注册账号，不上传孩子数据；无广告、无社交、无外链跳转 |
| 性能 | 首屏加载 ≤ 3 秒；可离线使用（PWA），含课本字库、拓展字库和笔顺数据 |
| 内容版权 | 不收录课文全文；字表、组词、字理说明使用自编或开源可商用数据；笔顺数据使用开源数据集并遵守其许可 |

## 6. 推荐技术形态

- **MVP 做成 Web 应用（PWA）**：一套代码可以在平板、电脑上运行，也能“添加到主屏幕”像 App 一样使用，还支持离线。不需要上架应用商店，迭代最快。
- **部署**：代码托管在 GitHub 仓库 `sivenDev/ihomework`，通过 GitHub Pages 免费发布（HTTPS）。托管的只是程序文件，孩子的学习数据只保存在平板本机。
- **以后需要时再打包成安卓 App**：用 Capacitor 打包成 APK 直接安装，复用同一套 Web 代码。
- 候选技术（实施计划阶段再确认）：
  - 前端：React + TypeScript + Vite
  - 本地存储：IndexedDB
  - 笔顺动画和描红：Hanzi Writer
  - 拼音：pinyin-pro
  - 语音朗读：浏览器自带的 Web Speech API（zh-CN）

## 7. 非目标（本期不做）

- 不做多家庭、多账号、云端同步和后台管理（P2 再考虑）。
- 不做任意手写识别和 AI 自动批改作文；屏幕书写只按标准笔顺逐笔比对（见 4.7A），纸上书写和作文由家长判定。
- 不覆盖数学、英语等其他学科；不内置三年级及以上的课本字表（基础好的孩子通过拓展字库继续学习）。
- 不做排行榜、社交分享、付费和广告。
- 不收录课文全文、教辅题库。

## 8. 验收标准（MVP）

1. 课本字库包含一年级上册至二年级下册 4 册，拓展字库包含一级字表中课本之外的字；家长可以设置课本进度到其中任意一课，并可修改字词；闯关、预习、复习出题范围与进度一致。
2. 完成一次完整评估后生成报告，包含课内识字量、待攻克清单、写作等级、建议学习路线和建议练习级别；课内认读 ≥ 90% 时自动加测拓展认读并估算课外识字量；报告保存到历史。
3. 部首侦探、字族网络、生字闪认三个玩法可玩，每关时长 ≤ 5 分钟，难度随正确率升降，最高难度包含拓展字；出错的字自动进入错字 Boss。
4. 错字 Boss 按第 1、2、4、7、15 天的间隔出现；连续 3 次正确后移进“战利品”；出错后间隔重置。有自动化测试覆盖这套调度逻辑。
5. 每日任务清单按进度、学习路线（补漏 / 同步 / 拓展）和练习级别（轻松 / 标准 / 加强）自动生成，预计时长符合该级别；加强级别分两段并提示中间休息；新字进入错字 Boss；Boss 积压时自动减少新字；路线按规则自动切换并提示家长；周末生成周 Boss 战。
6. 侦探看图写作可以走完“找线索 → 推理 → 写报告 → 句子升级 → 家长评分”的全流程；写作等级按规则提升。
7. 经验值和等级按规则累计，不出现扣分。
8. 家长看板展示识字量曲线（课内认读、书写、课外）、路线进度、写作等级、错字清单、打卡天数；数据可以导出为 JSON 并重新导入。
9. 描红和默写可以在平板上用手指完成，按笔顺逐笔判断，默写出错的字进入错字 Boss；课本字和拓展字都支持。
10. 在安卓平板 Chrome 和桌面 Chrome 上可用，断网后所有功能仍可使用；孩子模式下所有汉字可点读。
11. 数据只保存在本机，没有网络上传请求（离线字库与语音由浏览器提供）。

## 10. 已确认决策（2026-10-19）

1. 课本使用部编版（统编版），字库覆盖一年级上、下册和二年级上、下册。
2. 主要设备为安卓平板。
3. 初始字库由开发方按公开资料整理，家长之后在系统中自行核对、设置。
4. 需要在平板上描红和书写，列入 MVP（见 4.7A）。
5. 不需要多个孩子或多台设备同步。
6. 每日练习量分轻松、标准、加强 3 个级别（见 4.5.3）。
7. 先用免费托管：GitHub Pages，仓库 `git@github.com:sivenDev/ihomework.git`。
8. 系统面向不同基础的孩子，定位是“科学、有趣的语文学习方法”：基础薄弱的走补漏路线追上进度，基础好的走拓展路线继续提高（见 1、3A、4.5.2 节）。
