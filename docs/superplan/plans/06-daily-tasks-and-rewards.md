# 学习路线、三级练习量、每日任务与激励系统 Plan

**Goal:** 把预习、复习、学新字和挑战组织成每天固定的短流程；用“学习路线”决定练什么、用“练习级别”决定练多少，让基础弱的孩子能追上进度、基础好的孩子能继续提高，并用看得见的成长激励孩子坚持。

**Scope:**
- **三条学习路线**（PRD 4.5.2，系统自动切换，家长可锁定）：

  | 路线 | 进入条件 | 新字任务取什么字 |
  |---|---|---|
  | 补漏 | 待攻克清单不为空，或存在进度之前从未答对过的字 | 待攻克清单和以前没掌握的字，按课本顺序先早后晚 |
  | 同步 | 补漏清单已清空，但不满足拓展条件 | 本课和下一课中尚未掌握的字 |
  | 拓展 | 补漏清单已清空，且周 Boss 正确率连续 2 周 ≥ 90%；或首次评估课内认读 ≥ 90% 且书写 ≥ 85% | ① 超前学习后续课程的字（家长开启时）；② 已学字所在字族中的课外常用字；③ 拓展字库中按常用程度排序的字 |

  - 每天生成任务前重新判断路线；路线变化时在家长看板提示。
  - 拓展路线在补漏条件重新满足时（例如复评发现新的待攻克字）自动回到补漏。
- **三个练习级别**（PRD 4.5.3）：

  | 级别（孩子看到的名称） | 每日时长 | 新字/天 | Boss 上限 |
  |---|---|---|---|
  | 轻松（日常巡逻） | 约 15 分钟，1 段 | 0 | 10 |
  | 标准（侦探训练） | 约 20 分钟，1 段 | 3 | 15 |
  | 加强（特训营） | 约 30 分钟，2 段，每段 ≤ 15 分钟，中间休息 5 分钟；周末加 15 分钟特训闯关 | 8 | 25 |

  - 家长设置级别，并可在级别内微调新字数量、Boss 上限和时长。
  - 当天可以临时切到“轻松”，第二天自动恢复原级别。
  - 使用时长提醒（计划 01）改为读取当前级别的每段时长；加强级别第一段结束后显示休息倒计时，再进入第二段。
- **新字任务**：按“路线 × 级别配额”取字；先做一次部首侦探或字族学习，需要会写的字（写字表中的字；拓展字由家长设置是否要求书写，默认只认读）再描红，然后以来源 `backlog` / `sync` / `extension` 调用 `addMistake` 进入错字 Boss。
- **防过载**：当天到期的 Boss 卡已超过上限时，新字数量按超出量减少（最少为 0）；超出上限的 Boss 卡顺延到第二天。
- **每日任务清单**（孩子首页）：按级别生成预习“侦察任务”、当天复习（本课生字闪认）、新字任务、错字 Boss 战、阅读打卡（入口由计划 07 提供，本计划先占位）。每项标注预计时长，总和不超过级别时长；超出时按“Boss 战 → 当天复习 → 新字 → 预习”保留，其余标为“可选”。
- **级别建议**（只提示，不自动切换）：首次评估后采用计划 03 报告的建议级别作为默认值供家长确认；连续 3 天没完成必做任务 → 建议降一级；周 Boss 正确率连续 2 周 < 70% → 建议升一级或减少新字。
- **路线进度**：补漏路线显示“已攻克 / 剩余”和“预计还需几周补完”= 剩余字数 ÷（每日新字配额 × 最近 2 周平均每周练习天数）；拓展路线显示课外新学字数和每周增长，供家长看板（计划 08）显示。
- **周 Boss 战**：每周六起可用，从本周学过的字中抽 20 个，认读加默写（拓展字按家长设置只认读）；记录正确率并与上周对比。
- **单元挑战**：家长把进度推进到新单元时，为刚结束的单元生成一次综合挑战。
- **经验值与等级**：攻克 1 个字 +1，写作升一级 +5，读完 1 本书 +20，完成每日任务 +10（加强级别完成两段 +20）；称号为汉字学徒 → 部首侦探 → 字族猎人 → 文字大师（每个称号分 3 个小级，阈值集中定义）；只加不扣，升级时有庆祝动画。
- **奖励兑换**：家长在家长模式中设置奖励清单（名称、所需经验值）；孩子申请兑换，家长确认后扣除可用经验值（等级按累计经验值计算，不会因兑换下降）。
- **连续打卡天数**：完成当日必做任务即记一天。

**Non-Goals:**
- 不做排行榜、扣分、惩罚。
- 不做推送通知。
- 不做三年级及以上的课本进度（拓展路线使用拓展字库）。

**Architecture:**
- 路线判定、级别配置、取字、防过载、任务规划、级别建议、路线进度、经验值、等级都是纯函数，输入为日期、级别配置、路线锁定设置、进度、待攻克清单、作答记录、错字卡和周 Boss 历史。
- 级别配置集中定义在 `src/features/daily/logic/levels.ts`，家长微调值覆盖默认值。
- 拓展取字依赖计划 02 的拓展候选查询（超前课程、字族课外字、常用度排序），三类来源按 ①→②→③ 轮转，保证新鲜感。
- 经验值以事件表累加，事件带唯一 id，保证同一事件不会重复加分；“累计经验值”决定等级，“可用经验值”用于兑换，分开存储。

**Exit Criteria:**
- 单元测试覆盖：三条路线的进入和切换条件（含首次评估直接进入拓展、拓展回到补漏、家长锁定）；三个级别生成的任务内容、时长与分段；各路线按配额和顺序取字（补漏先早后晚、拓展三类来源轮转、超前学习开关）；Boss 积压时减少新字（含减到 0）；当天临时降级不影响第二天；级别建议规则及其边界；路线进度与预计周数；任务总时长裁剪；周 Boss 只抽本周字；单元挑战触发；经验值不重复发放；兑换后等级不变。
- Playwright：
  - “加强 + 补漏”：完成两段任务（中间出现休息倒计时）后连续天数 +1、经验值增加，补漏字出现在错字 Boss 中。
  - “标准 + 拓展”：新字任务出现拓展字，拓展字默认只认读。
  - 家长切换级别、锁定路线后首页任务随之变化；家长添加奖励、孩子申请、家长确认兑换的完整流程。
- `npm run verify` 与 `npm run test:e2e` 通过。
