# 汉字闯关使用说明

地址：<https://sivendev.github.io/ihomework/>

## 1. 在安卓平板上安装

1. 用 **Chrome** 打开上面的地址。
2. 第一次打开时，左下角会显示“正在下载离线数据”。这一步会下载课本字库、拓展字库和约 3600 个字的笔顺数据，共约 12 MB。请连着 Wi-Fi 等它走到 100%，看到“离线数据已准备好，断网也能用”。
3. 点 Chrome 右上角的 **⋮ → 添加到主屏幕**（有的平板显示为“安装应用”）。
4. 以后从主屏幕上的“汉字闯关”图标打开。它会全屏横屏显示，和普通 App 一样。

## 2. 断网使用

下载完离线数据后，断网也能使用全部功能：闯关、描红默写、错字 Boss、每日任务、看图写作、阅读打卡、家长看板。

点读汉字用的是平板自带的“文字转语音”。如果听不到声音，请到系统 **设置 → 文字转语音** 里安装中文语音包。语音包装好后，断网也能用。

## 3. 更新

我们发布新版本后，平板联网打开应用时会在后台下载更新，只下载有变化的文件。下载完成后，左下角会显示“有新版本了”。孩子练完后点 **更新** 即可。不点就继续用旧版本，不会在练习中途突然刷新。

## 4. 第一次设置（家长）

1. 点首页右上角的 **家长**，设置 4 位家长 PIN。之后可以在“设置与管理 → 家长 PIN”里修改。
2. **课本与字库**：把课本进度设为孩子正在学的那一课。
3. **现状评估**：做一次评估。系统会给出学习路线和练习级别的建议，还会定出写作等级的起点。
4. **练习级别与路线**：确认练习级别（轻松、标准或加强），需要时调整每天的新字数和每段时长。
5. **奖励清单**：添加孩子可以用经验值兑换的奖励。

家长模式首页就是看板，可以看到识字量曲线、路线进度、写作等级、错字清单、打卡天数和近 7 天用时。

## 5. 数据与备份

- 学习数据**只保存在这台平板上**：不需要注册账号，也不会上传。
- 清除 Chrome 的网站数据、卸载 Chrome，或者换平板，数据都会丢失。请定期到 **家长模式 → 数据备份 → 导出备份**，把导出的 JSON 文件保存到网盘或电脑上。
- 换设备时，在新平板上安装应用，然后用 **从备份恢复** 选择这个文件。恢复会覆盖新设备上的现有数据。
